# VLA 기반 딸기 수확 파이프라인

## 개요

VLA(Vision Language Action) 모델을 활용한 end-to-end 딸기 수확 파이프라인입니다. 
명시적인 규칙 기반 처리 없이, 학습된 정책이 실시간 카메라 이미지와 로봇 상태로부터 직접 제어 액션을 생성합니다.

---

## 상세 동작 단계

### 1. 입력 준비 및 타겟 선정

- **Base view 이미지** (224×224 RGB)
  - 전체 식재 지역에서 수확 대상 딸기 선정
  - 광각 카메라로부터 캡처

- **Wrist view 이미지** (224×224 RGB)
  - 선정된 딸기의 근접 영상
  - 그리퍼 근처 카메라로부터 캡처

- **현재 로봇 상태 벡터** (32-dim)
  ```
  [TCP_x(m), TCP_y(m), TCP_z(m), Rx(rad), Ry(rad), Rz(rad), gripper_ratio(0-1)] + 25×padding
  ```
  - TCP pose: 그리퍼 끝단의 3D 위치 및 자세
  - gripper_ratio: 그리퍼 개폐도 (0=완전 개방, 1=완전 폐쇄)

- **자연어 명령**
  ```
  "Align gripper to strawberry stem and grasp it"
  ```
  - 수확 의도를 명시적으로 표현

- **에피소드 초기화 플래그**
  - `reset_episode=True`: 새로운 타겟에 대한 에피소드 초기화

---

### 2. [반복 추론 루프 - Stage 1] X축 정렬

**목표**: 그리퍼가 딸기 줄기의 X축 방향과 정렬

**VLA 입력**:
- 현재 Base/Wrist 이미지
- 현재 상태 벡터
- instruction: "Align gripper to strawberry stem and grasp it"

**VLA 출력**: 32-dim 액션 벡터

**실행 액션**:
- `delta_ry` (Y축 회전): 딸기 줄기의 수평 각도와 맞춤 (±30deg 범위)
- `delta_x`, `delta_z`: 미세 위치 조정 (X축 정렬에 필요한 경우)

**수렴 조건**:
- 그리퍼 방향과 줄기 X축 방향의 각도 오차 < 5deg
- Wrist 카메라로부터 판단

**반복 종료 조건**:
- 수렴 조건 만족 **또는**
- 최대 5회 추론 시

**다음 단계**: Stage 2로 진행

---

### 3. [반복 추론 루프 - Stage 2] Z축 정렬

**목표**: 그리퍼가 딸기 위에 올바른 높이에 위치하도록 정렬

**VLA 입력**:
- 현재 이미지 (X축 정렬된 상태)
- 업데이트된 상태 벡터
- instruction

**VLA 출력**: 32-dim 액션 벡터

**실행 액션**:
- `delta_z` (상하 이동): 현재 높이를 딸기 줄기 KP0(파지점)과 일치시킴
- `delta_rz` (Z축 회전): 필요시 그리퍼 회전축을 수직으로 정렬
- `delta_x`, `delta_y`: 미세 위치 조정

**수렴 조건**:
- 현재 Z 높이가 목표 높이(KP0 기준)와 ±5mm 이내

**반복 종료 조건**:
- 수렴 조건 만족 **또는**
- 최대 5회 추론

**다음 단계**: Stage 3으로 진행

---

### 4. [반복 추론 루프 - Stage 3] Y방향 진입 + 줄기 방향 정렬

**목표**: 그리퍼를 Y방향으로 전진시키면서 회전축을 줄기 방향과 정렬

**VLA 입력**:
- 현재 이미지 (X, Z 정렬 완료)
- 업데이트된 상태 벡터
- instruction

**VLA 출력**: 32-dim 액션 벡터

**실행 액션**:
- `delta_y` (전진): Y방향으로 점진적 접근
  - 범위: +50mm ~ +100mm
  - 한 번 추론 당: 약 20mm
  
- `delta_rx`, `delta_rz` (회전): 줄기 방향 벡터와 그리퍼 회전축 정렬
  - 줄기 기울임 각도를 학습 과정에서 암시적으로 인식
  - Wrist 카메라에서 실시간 피드백으로 회전축 미세 조정
  
- `delta_x`, `delta_z`: 접근 중 위치 보정 (±20mm 범위)

**수렴 조건**:
- 그리퍼와 줄기의 상대 거리 < 30mm
- 회전축 오정렬 < 10deg

**반복 종료 조건**:
- 수렴 조건 만족 **또는**
- Y 진입 거리 누적 > 150mm **또는**
- 최대 10회 추론

**다음 단계**: Stage 4로 진행

---

### 5. [한 번의 추론] 파지 (그리퍼 클로즈)

**목표**: 그리퍼를 닫아서 KP0-KP1 중간점 (또는 KP0-KP2 중간점) 파지

**VLA 입력**:
- 최종 접근 이미지 (X, Z, Y 방향 정렬 완료)
- 상태 벡터
- instruction

**VLA 출력**: 32-dim 액션 벡터

**실행 액션**:
- `gripper_ratio`: 1.0 (그리퍼 완전 클로즈)
  - 또는 학습된 최적 폐쇄도 적용
  
- `delta_x`, `delta_y`, `delta_z`: 거의 0에 가까운 값 (위치 고정)
- `delta_rx`, `delta_ry`, `delta_rz`: 거의 0에 가까운 값 (자세 고정)

**실행 과정**:
- Teleop `/gripper` 명령 실행
- 완료 대기 (타임아웃: 2초)
- 그리퍼 힘(force) 피드백으로 파지 성공 여부 판단

**다음 단계**: Stage 5로 진행

---

### 6. [한 번의 추론] 분리 이동 (-Z 방향)

**목표**: -Z 방향(아래 방향)으로 딸기를 분리

**VLA 입력**:
- 파지 완료 이미지
- 파지된 상태의 로봇 상태 벡터
- instruction

**VLA 출력**: 32-dim 액션 벡터

**실행 액션**:
- `delta_z`: -150mm ~ -200mm (진입 거리의 역방향)
- `delta_y`: 0mm (Y 방향 유지, 줄기와 분리 방향 일치)
- `delta_rx`, `delta_ry`, `delta_rz`: 거의 0 (자세 유지)

**실행 방식**:
- 선형 이동 (MoveLine 개념)
- Z축 직선 경로 유지

**수렴 조건**:
- Z 이동 거리 누적 = 진입 거리

**다음 단계**: Stage 6으로 진행

---

### 7. [반복 추론 또는 역경로 추적] 홈 포즈 복귀

**목표**: 진입 경로의 역순(Y← → Z↑ → 초기 자세)으로 이동하여 홈 포즈 도달

**VLA 입력**:
- 분리 완료 이미지
- 현재 상태 벡터 (파지된 상태)
- instruction

**VLA 출력**: 32-dim 액션 벡터

**실행 액션** (반복):

1. **Stage 3의 역순**: Y방향 후진
   - `delta_y`: -20mm ~ -30mm씩
   - 누적 Y 거리만큼 후진

2. **Stage 2의 역순**: Z축 상승
   - `delta_z`: +20mm ~ +30mm씩
   - 누적 Z 거리만큼 상승

3. **Stage 1의 역순**: 초기 자세 복귀
   - `delta_rx`, `delta_ry`: 음수로 설정
   - 초기 자세 복귀

4. **최종**: 홈 포즈 도달
   - 사전 정의된 홈 포즈: `[TCP_x0, TCP_y0, TCP_z0, Rx0, Ry0, Rz0]`

**반복 종료 조건**:
- 거리 임계값 < 30mm **또는**
- 최대 15회 추론

**마무리**:
- `gripper_ratio`: 0 (그리퍼 오픈, 딸기 놓기)
- `reset_episode=False`: 다음 추론을 위한 초기화 해제

**에피소드 종료**: 로그 저장 및 학습 데이터 수집

## 액션 역정규화 및 안전 검증

**모든 단계에서 동일하게 적용**

### 델타 이동값 변환

```python
# 정규화된 델타값 → 로봇 단위
delta_mm = [d * 1000 for d in delta_m]           # m → mm
delta_deg = [d * 57.2958 for d in delta_rad]    # rad → deg
```

### 안전 클램핑

```python
# 각 축별 이동 범위 제한
delta_mm = [max(-200, min(200, d)) for d in delta_mm]    # ±200mm
delta_deg = [max(-30, min(30, d)) for d in delta_deg]    # ±30deg

# 그리퍼 범위 정규화
gripper_raw = max(0, min(740, int(gripper_ratio * 740)))
```

### IK 검증

- 목표 pose가 로봇 작업 공간 내인지 확인
- 역기구학 계산 실패 시: 해당 액션 취소

### Joint Limit 검증

- 각 관절이 `JOINT_SAFETY_MARGIN (90%)` 이내인지 확인
- 한계 초과 시: 해당 액션 취소, 오류 메시지 로깅

**실패 처리**:
- IK/Joint limit 검증 실패 → 해당 Stage 액션 취소
- 오류 메시지 기록 → 복귀 절차 시작
- 안전 우선 정책: 불확실한 명령은 실행 금지

## Teleop API를 통한 로봇 순차 실행

**모든 단계에서 동일**

### 각 축별 순차 이동

```
dx 이동 → dy 이동 → dz 이동 → drx 회전 → dry 회전 → drz 회전
```

### 노이즈 필터링

- 미세한 이동 < 0.1mm/deg: 자동 스킵

### 실행 대기

- 각 축 이동 후 성공 여부 확인
- 타임아웃: 5초

### 그리퍼 제어

- Teleop `/gripper` 엔드포인트 호출
- 타임아웃: 2초

### 부분 성공 처리

- 한 축이라도 실패 시:
  - 이후 축 실행 중단
  - 부분 성공으로 처리
  - 현재 상태 저장 후 다음 추론에 반영

## 실시간 피드백 및 상태 업데이트

**각 Stage 반복 시마다 실행**

### 로봇 상태 벡터 갱신

```python
state_vec = [
    tcp_pose[0] / 1000.0,      # TCP X: mm → m
    tcp_pose[1] / 1000.0,      # TCP Y: mm → m
    tcp_pose[2] / 1000.0,      # TCP Z: mm → m
    tcp_pose[3] / 57.2958,     # Rx: deg → rad
    tcp_pose[4] / 57.2958,     # Ry: deg → rad
    tcp_pose[5] / 57.2958,     # Rz: deg → rad
    gripper_pos / 100.0,       # gripper: [0-100] % → [0-1] ratio
] + [0.0] * 25
```

### 카메라 프레임 갱신

- Base/Wrist 이미지 실시간 캡처
- 224×224 리사이즈 + base64 인코딩

### VLA 재입력

- 업데이트된 상태와 이미지로 다음 액션 추론

### 반복 횟수 추적

- 각 Stage별 최대 반복 횟수 제한
- 무한 루프 방지

## 에러 처리 및 복구

### VLA API 응답 없음

**증상**: 타임아웃(5초) 또는 네트워크 오류

**대응**:
- 해당 Stage 재시도 (최대 3회)
- 3회 초과 시: Stage 스킵, 다음 단계로 진행

### IK 실패

**증상**: 목표 pose 도달 불가능

**대응**:
- 현재 Stage에서 ±50mm 오프셋으로 재계산
- IK 재계산 실패 시: 해당 액션 취소

### Joint Limit 초과

**증상**: 안전 위반

**대응**:
- 해당 액션 취소
- Stage 반복 (더 작은 delta 값으로)
- 반복 횟수 초과 시: Stage 스킵

### Teleop API 통신 실패

**증상**: 로봇 미응답

**대응**:
- 부분 성공 처리
- 다음 추론에 현재 상태 반영
- 재시도 없음 (딜레이 방지)

### 반복 횟수 초과

**증상**: Stage 수렴 실패

**대응**:
- 해당 Stage 스킵
- 다음 Stage로 진행 (부분 성공)
- 로그에 "convergence_failed" 기록

### 파지 실패

**증상**: 그리퍼 힘 피드백 부족

**대응**:
1. `gripper_ratio` 증가 시도
2. 다시 파지 시도 (최대 2회)
3. 실패 시: 복귀 절차 강제 실행

### 최종 실패

**증상**: 복구 불가능한 오류

**대응**:
- 복귀 절차 강제 실행
- 홈 포즈로 즉시 이동
- gripper 오픈 (딸기 안전하게 놓기)
- 에피소드 종료 및 상세 오류 로깅

## 주요 특징

### 1. 엔드투엔드 학습
- 명시적인 YOLO, HSV 필터링 없음
- 학습된 정책이 직접 제어

### 2. 다단계 정렬 전략
- X축 정렬 → Z축 정렬 → Y방향 진입

# VLA 기반 딸기 수확 파이프라인 (간단 버전)

1. Base view (224×224) + Wrist view (224×224) 카메라 이미지 입력
2. 현재 로봇 상태 벡터 입력 (TCP pose, gripper ratio를 정규화된 형태로)
3. 자연어 명령 입력 ("Grasp the strawberry stem and pick it.")
4. VLA 모델이 이미지 + 상태 + 명령으로부터 32-dim 액션 벡터 직접 생성
5. 액션의 [0:3] delta_m, [3:6] delta_rad, [6] gripper_ratio 추출 및 역정규화 (m→mm, rad→deg)
6. IK/Joint limit 안전 검증 및 ±200mm/±30deg 클램핑
7. X축 정렬 → Z축 정렬 → Y방향 진입 + 줄기 방향 정렬을 반복 추론으로 순차 수행
   - 각 단계마다 상태 벡터 업데이트 및 카메라 이미지 갱신
   - 수렴 조건(각도 오차 < 5deg, 거리 오차 < 30mm) 만족 시 다음 단계로 진행
8. 그리퍼를 닫아(gripper_ratio=1.0) 목표 지점(KP0-KP1 중간점) 파지
9. -Z축 방향으로 이동하여 딸기 분리 (진입 거리의 역방향)
10. 진입 경로의 역순(Y← → Z↑ → 초기 자세)으로 반복 추론하여 홈 포즈 복귀 + 그리퍼 오픈
