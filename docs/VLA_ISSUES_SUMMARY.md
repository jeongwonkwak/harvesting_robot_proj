# VLA 추론 이상 원인 추적 — 전체 이슈 정리표

> **원본 상세 기록**: `VLA_DAILY_ISSUES.md` | **기간**: 2026-06-08 ~ 2026-06-10 | **대상**: pi05 학습·추론 파이프라인 / `vla_dataset_v0.4.x` → `v0.5.0`
> **마지막 업데이트**: 2026-06-10

---

## 배경 — 무엇이 문제였나 (추적의 출발점)

딸기 수확 태스크용 pi05 VLA 모델을 학습시킨 뒤 추론을 돌려보니, **모델이 학습 데이터에서 보여준 궤적대로 움직이지 않는** 현상이 발생했다. 학습 loss는 0.1대까지 정상적으로 수렴했는데도 실제 추론 출력은 다음과 같이 이상했다:

- **방향이 반대**: 학습 데이터는 -X 방향으로 이동하는데 추론은 +X 방향을 예측 → 로봇이 딸기 반대쪽으로 움직일 위험
- **출력 범위 이상**: 모델 출력이 학습 action 범위(예: ΔX -21.85~+86.52mm)와 맞지 않는 값 → 의도치 않은 큰 움직임, 잘못된 그리퍼 명령
- **정지해야 할 때 움직임**: 가만히 있어야 하는 장면에서도 +33mm 수준의 이동 명령이 출력됨
- **데이터 자체도 의심**: 검증 과정에서 state 그리퍼 값 0.001 고정, Joint State 6축 전부 고정값(std=0) 등 학습 데이터 이상 발견

원인이 **추론 파이프라인(학습-추론 불일치)에 있는지, 학습 데이터 품질에 있는지** 알 수 없는 상태에서, 데이터 검증(06-08) → 파이프라인 정밀 점검(06-09) → 전수 검증 및 원인 확정(06-10) 순으로 추적했다.

## 한 줄 결론

> **추론 파이프라인 버그 5건은 전부 수정 완료 (학습-추론 100% 일치 검증). 남은 모델 출력 이상의 근본 원인은 "버튼 스텝 방식 텔레오퍼레이션"으로 수집된 학습 데이터의 구조적 한계(정지 75% + 뾰족한 계단 패턴) → 텔레오퍼레이션을 TCP 좌표 move_spline 방식으로 전환해 완만한 연속 action으로 재수집(`v0.5.0`), 현재 재학습 진행 중.**
